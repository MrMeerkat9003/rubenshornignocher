# Ruben — Interactive Photo Archive

Open `index.html` in a browser. No server, dependencies, or installation required.

## Included photos
- Original images: `images/Ruben1.jpeg` through `images/Ruben8.jpeg`
- Newly imported images: `images/Ruben9.jpeg` through `images/Ruben47.jpeg` (39 photos from images.rar, in archive order)
- **47 photos total**. All 47 are explicitly included in the JavaScript photo list and packed in this ZIP.

## Add more photos
Place `Ruben48.jpeg`, `Ruben49.jpeg`, `Ruben50.jpeg`, and so on in the `images/` folder with no gaps. The gallery will look for consecutive additional JPEGs automatically. For custom photo titles and descriptions, edit the photo list near the top of `script.js`.

## Features
Browse 47 photos in the gallery and spotlight, search, sort, shuffle, filter and save favourites locally. Click images to open the full-screen lightbox. Navigate with arrows/swipes, save, or download. Includes light/dark mode and responsive mobile navigation.
